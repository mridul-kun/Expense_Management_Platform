            About account connections

            XpFlow runs entirely as static HTML, CSS and JavaScript, so it never asks for your real net-banking username or password — that kind of link needs a licensed backend (like a Plaid, TrueLayer or Yodlee integration) to talk to your bank securely. Instead, "Connect account" here adds an account you describe, and "Sync" simulates new transactions arriving so you can see how the ledger behaves. Swap the simulated sync in script.js for a real API call once you have a backend, and the rest of the app keeps working as-is.
